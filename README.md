# AI Mail Companion 📧🤖

AI Mail Companion is a modern email management platform that helps users
organize, analyze, and respond to emails using AI-powered tools.

## 🚀 Features
- Inbox management
- Email threads & attachments
- AI summaries & reply drafting
- Multi-account email support
- Secure authentication
- PostgreSQL + Prisma backend

## 🧱 Tech Stack
### Frontend
- React
- TypeScript
- Tailwind
- shadcn/ui

### Backend
- Node.js
- Express
- Prisma ORM
- PostgreSQL (Neon)

## 🛠 Setup

### Backend
```bash
cd backend
npm install
npx prisma migrate dev
npm run dev
